# 项目实现说明

## 1. 项目定位

该项目是一个面向固定实验场景的 RGB-D 视觉引导激光云台原型。目标区域包含圆形靶盘内部的红、绿、蓝圆形靶标，以及靶盘外部的彩色目标。二维码用于指定目标颜色顺序。

它的主要价值是打通了以下完整链路：

```text
RGB-D 感知 → 目标定位 → 几何换算 → 串口通信 → 云台执行
```

项目当前采用传统计算机视觉作为主线。GroundingDINO 只存在于实验版本中，不应视为主系统已经完成的能力。

## 2. 核心算法

### 深度 ROI

`utils/roi.py` 将深度图限制在指定范围，按深度区间切片，选择像素数最多的切片，再经过形态学处理、最大连通域筛选和最小外接圆拟合得到靶盘 ROI。

### 内部三色目标

`utils/detect.py` 使用 Hough Circle 生成候选圆，保留三个主要候选，并根据圆内 HSV 特征计算其与红、绿、蓝参考颜色的距离。程序枚举候选圆与颜色的一对一分配，选择总代价最小的组合。

### 外部目标

靶盘外部区域由 ROI 的反掩码获得。程序分别使用红、绿、蓝 HSV 范围生成二值掩码，并以每种颜色的最大轮廓中心作为目标坐标。

### 激光光斑

`utils/laser.py` 先压低图像曝光，再通过灰度亮度阈值提取高亮区域，并使用最大轮廓中心和时间中值滤波估计光斑位置。

### 坐标换算

系统用靶盘真实直径除以检测到的像素直径，得到近似毫米/像素比例。目标相对靶盘中心的平面偏移与深度一起转换为俯仰角和偏航角。

## 3. 版本说明

- `class521_9_color_final_final.py`：当前主线，使用几何模型直接计算目标角度。
- `class521_9_color_final_final_close.py`：根据目标与激光点的角度差做比例修正的闭环实验。
- `class521_9_color_final_final_dino.py`：GroundingDINO 检测实验，尚未完成依赖和接口统一。
- `class521_9_color_final_final_wzy.py`：协作产生的简化版本。
- `class521_9_color_final_offline.py`：保存/加载 RGB-D 帧的离线调试版本。

## 4. 已知风险

1. 深度 ROI 找不到有效切片或轮廓时，部分变量可能未初始化。
2. 深度高低字节当前按 `low + high * 255` 合成，需要结合 OpenNI 数据格式确认是否应使用 256。
3. 主程序只在初始化阶段检测一次外部目标，场景移动后不会自动更新。
4. 激光检测缺少面积、圆度、颜色和目标邻域约束，容易受到环境高光影响。
5. 光斑滤波缺少数据失效时间，检测中断后可能继续使用旧坐标。
6. 毫米/像素比例没有显式使用相机内参、畸变和 RGB-D 外参。
7. ROI 中心修正、140 mm 安装偏置、串口号等均为硬编码。
8. 串口实现与注释中的字段长度不一致，且没有帧头、校验、ACK 和重试机制。
9. 离线版本存在重复函数和深度单位处理不统一的风险。
10. DINO 实验版本与当前 ROI 接口尚未完全同步。

## 5. 推荐评测指标

后续工程化时至少记录：

- 内部/外部目标检测成功率
- 激光点检测成功率与误检率
- 静态端点误差（像素、毫米、角度）
- 从初始偏差到稳定命中的收敛时间
- 闭环稳定后的抖动标准差
- 不同距离、亮度和靶盘角度下的成功率
- 图像处理 FPS、串口控制频率和端到端延迟

## 6. 推荐升级路线

1. 将硬件配置和算法阈值迁移到 YAML。
2. 修复所有空输入与设备异常路径。
3. 采用标定板求相机内参和畸变参数。
4. 标定相机光心、激光发射点和云台旋转轴之间的外参。
5. 将光斑误差真正纳入连续 P/PID 视觉伺服。
6. 增加死区、控制限幅、积分抗饱和和目标丢失保护。
7. 建立可重复的离线数据集与定量评测脚本。
